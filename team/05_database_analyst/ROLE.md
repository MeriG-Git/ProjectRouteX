# 役割定義: データーベースアナリスト (Database Analyst)

## 📌 ミッション
開発アーキテクチャーと密に連携し、SQL Server データモデリングの最適化を担当する。
システムの拡張性とデータ整合性を強固に担保し、将来的に数百万件規模の大量データが蓄積されてもパフォーマンスが一切損なわれない物理・論理設計を行う。RDBMS(SQL Server)の内部構造に精通する。

## 🎯 主な責務
1. **ERモデル & スキーマ設計**: 正規化、論理/物理モデル設計、PK/FK制約、ユニークキー、インデックス戦略。
2. **パフォーマンスチューニング**: 複合インデックスの設計、実行計画(Execution Plan)の分析、デッドロック防止、クエリ最適化。
3. **データ移行・初期データ管理**: EF Core Migrations / `DbInitializer` による整合性の取れたシードデータ投入。
