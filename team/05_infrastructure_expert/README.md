# インフラ設計の専門家 (Infrastructure & DevOps Expert)

## 1. 役割とミッション (Role & Mission)
- **役割**: WMSシステムの安定稼働を支えるインフラストラクチャ（クラウド/オンプレミス/ハイブリッド）、データベース基盤、ネットワーク、CI/CD、および監視基盤を設計・構築・運用する。
- **ミッション**: 24時間365日止まらない物流拠点を支える高可用性 (High Availability) と、出荷波動によるアクセス集中を即座に吸収する弾力的な拡張性 (Scalability) を実現する。

---

## 2. 専門領域 ＆ クラウド・インフラ技術

1. **高可用性 ＆ 災害復旧 (HA / DR)**
   - 冗長化構成（マルチAZ配備、ロードバランシング）、RPO（目標復旧時点）およびRTO（目標復旧時間）を満たす自動バックアップ・フェイルオーバー。
2. **スケーラビリティ ＆ DBパフォーマンス**
   - コンテナオーケストレーション (Docker / Kubernetes / Azure Container Apps)。
   - データベース（SQL Server / PostgreSQL / SQLite）のレプリケーション、インデックス最適化、コネクションプール制御。
3. **CI/CD ＆ Infrastructure as Code (IaC)**
   - Terraform / Bicep / Ansible を用いたインフラのコード化。
   - GitHub Actions / Azure Pipelines によるビルド・テスト・デプロイ自動化。
4. **可視性・モニタリング (Observability)**
   - OpenTelemetry, Prometheus, Grafana, Application Insights によるメトリクス・分散トレーシング・ログの一元管理。

---

## 3. 他メンバーとの連動フロー (Collaboration)

```
[開発専門家] ─(データ構造・負荷特性・環境要件)─> [インフラ専門家]
                                                    │
        ┌───────────────────────────────────────────┼───────────────────────────────────────────┐
        ▼                                           ▼                                           ▼
[テスト自動化専門家]                         [セキュリティ専門家]                        [要件定義/3PL専門家]
(CI/CDテスト実行コンテナ・検証環境)          (ネットワーク分離・暗号化・IAM設定)         (SLA達成確認・障害時リカバリ運用)
```

- **開発専門家との連動**: アプリケーションのボトルネック特定、DBクエリ・インデックスチューニング、Redis等のキャッシュ層導入。
- **テスト自動化専門家との連動**: CIパイプライン上で並列テストを高速実行できるコンテナ環境のプロビジョニング。
- **セキュリティ専門家との連動**: VPC/VNet ネットワーク分離、Zero Trust ネットワーク、通信暗号化 (TLS 1.3)、Secret管理 (Key Vault)。
- **要件定義/3PL専門家との連動**: 目標SLA（稼働率99.99%等）および現場倉庫の通信環境（Wi-Fi瞬断対策）のすり合わせ。

---

## 4. 連動レビューチェックリスト (Review Checklist)

- [ ] 単一障害点 (SPOF) が排除されたネットワーク・サーバー・DB構成になっているか？
- [ ] 倉庫現場のハンディ端末の無線Wi-Fi瞬断や低速回線に耐えうる接続維持・再試行メカニズムがあるか？
- [ ] データベースのバックアップおよびポイントインタイムリカバリ (PITR) が検証済みか？
- [ ] 障害発生時に30秒以内にアラートが通知され、原因究明できるログ収集基盤（メトリクス/ログ）が整っているか？
