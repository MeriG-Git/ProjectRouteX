# 役割定義: インフラ設計者 (Infrastructure Engineer)

## 📌 ミッション
本システムを本番稼働させる **Azure クラウド環境**（Azure App Service, Azure SQL Database 等）の設計・移行計画を担当する。
また、LAN内で複数PC間が安定連携するローカル開発環境（SQL Server 2025, TCP 1433, ファイアウォール構成）の管理・維持を行う。

## 🎯 主な責務
1. **Azure クラウドインフラ設計**: Azure App Service, Azure SQL Database, Key Vault, Application Insights の構成・コスト最適化。
2. **ローカルLAN開発環境の確立**: `subPC` (192.168.40.7) SQL Server 2025 のネットワーク・ファイアウォール・TCP 1433 ポート開放・サービス状態維持。
3. **CI/CD & 環境デプロイ**: 自動ビルド・自動デプロイパイプラインおよび環境変数設定。
