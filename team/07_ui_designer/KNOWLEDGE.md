# ナレッジベース: UIデザイナー

## 📌 デザイン規約 & トークン

### 1. デザインガイドライン
- **CSS方針**: Vanilla CSS による最大柔軟性とパフォーマンス制御（Tailwindを使用する場合は要確認）。
- **タイポグラフィ**: `Inter`, system-ui, sans-serif
- **カラーシステム**:
  - Primary: `#4f46e5` (Indigo Gradient)
  - Secondary: `#06b6d4` (Cyan Accent)
  - Dark Slate Background / Glassmorphic Card Surface

### 2. インポート画面のUI/UX統一ルール（リアルタイム進捗通知・件数％表示）
- 単純なローディング表示（アニメーションのみで進捗件数が不明な状態）は**UI設計不備（不統一障害）**とみなす。
- ユーザーに通知すべき要素を正しく把握し、すべてのインポートUIで以下の進捗情報をリアルタイム提示すること：
  1. **総件数および完了件数**: 例 `1,200 / 5,000 件` (カンマ区切り)
  2. **進捗パーセンテージ**: 例 `24%` (リアルタイムアニメーションバー)
  3. **処理中の対象キー情報**: 例 `処理中: 横浜市中区`
  4. **二重送信防止と完了・エラーの即時通知**
- 共通UIコンポーネント (`import-progress.js` / `submitImportStream`) をすべてのインポート画面へ水平展開適用すること。
