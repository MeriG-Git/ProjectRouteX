# ナレッジベース: プロジェクトマネージャー

## 📌 管理方針 & 知識蓄積

### 1. プロジェクト基本情報
- **システム名**: ProjectRouteX (ヤマキ物産特化型WMS)
- **コア原則**:
  - 全エージェントは隠し事をせず、決定事項や知見を `KNOWLEDGE.md` にオープンに記録する。
  - DBは SQL Server 2025 (`subPC` / `RouteXWmsDb`) に完全統一。
  - ドキュメントおよびコードコメントはすべて日本語で記述する。

### 2. 進行中の主タスク & 協議ルール
- 認証・認可基盤（RBAC/Claims）の刷新計画の策定。
- **マルチエージェント協議ルール**: 仕様・設計・インフラに関わる重要決定は関連エージェント間（開発アーキテクト、セキュリティ管理者、DBアナリスト、UIデザイナー、PM等）で必ず事前協議を行い、回答時に参加エージェント一覧を明記することを原則化。
- ローカル開発環境と将来のAzure公開環境でコード切り替えを行わない共通認証設計を確定。
